# groknode

> Keep Grok's local-computer capability running 24/7 — without leaving your desktop on.

- A single, self-contained Go binary
- Runs Grok Bot's official daemon **headlessly** on an always-on Linux box
- No display server, no GUI — just a hardened systemd service
- Ships **no proprietary code**. MIT-licensed, fully open source
